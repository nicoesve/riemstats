# What may enter this repository

Read by `/sync-repos` before every push. Judge content, not names: a file that mentions a dataset is fine; a file that carries restricted results is not. Change this file only on Control's ruling.

Restricted: real-subject data or results derived from it (HCP, SFARI, CLEAR, BRIGHT, client data). Allowed: source, manuscripts, figures and summaries of simulations, package data objects built from simulation or public data. A large data file (over 10 MB) is reviewed before it goes out even when it is simulated.
